# Simple interface brief

## Request
The owner asked for a much simpler design resembling an ordinary student coder’s website, and for all code comments to be removed. This direction replaces the previous dark dashboard brief.

## Design
Use a plain white page, dark system text, standard blue links and buttons, thin borders and straightforward forms. Keep a centered 880px workspace with one set of gutters. Navigation should wrap naturally; secondary decorative content should not compete with the actual tools. Keep the small [u] mark, accessible labels and visible keyboard focus. No custom fonts, framework, animations or new dependencies.

## Behavior to preserve
File fingerprints, local URL review, case records, recovery guidance, selective reporting packets, retained drafts, encrypted vaults and downloads must continue working. No uploaded evidence, visitor accounts or paid services. Hashes must not be described as deepfake detection.

## Acceptance
Inspect desktop and 320px screens, exercise link review and report navigation, run the existing JavaScript and Python suites, verify the source archive, publish the source to the owner-authorized public usualCyberSec repository, and update the existing Pages deployment.

Code comments and Python docstrings are removed; interpreter shebang directives and license documents remain. The file inventory is in FILES.md.
