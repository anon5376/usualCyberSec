# Bundled assets

These files are copied into the static application package for self-hosting. Font files are unmodified and carry their complete license texts alongside them.

| Asset | Source and author | License | Local files |
|---|---|---|---|
| Space Grotesk variable | [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/spacegrotesk); Space Grotesk Project Authors, typeface by Florian Karsten | SIL Open Font License 1.1 | `dist/fonts/SpaceGrotesk[wght].ttf`, `dist/fonts/SpaceGrotesk-OFL.txt` |
| IBM Plex Mono Regular | [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/ibmplexmono); IBM Corp. | SIL Open Font License 1.1 | `dist/fonts/IBMPlexMono-Regular.ttf`, `dist/fonts/IBMPlexMono-OFL.txt` |
The font binaries were obtained from the official Google Fonts repository's `ofl/spacegrotesk` and `ofl/ibmplexmono` directories. Their matching `OFL.txt` files are included in full.

The `docs/ASSETS.md` record provides provenance. It does not imply that the interface currently uses every bundled asset.
