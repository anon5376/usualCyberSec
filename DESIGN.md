# usualCyberSec 0.8.0

Operate mode. A quiet, useful local security notebook for someone who needs a next step now. Start with the actual link checker; five ordinary navigation links expose files, incidents, response guides and encrypted data. No landing-page detour, dashboards or decorative cards.

A single 1120px shell contains the header and work area. Tool forms use a 680px main column, with concise help in a separated side column. Incidents use plain divided rows. The destination hostname is the strongest result; all uncertain outcomes state the limit beside the answer. On phones the navigation wraps and the help follows the task.

Use Arc's neutral light foundation, locally hosted Inter for body and Geist for headings, regular and medium weights, 4px spacing steps, native semantic links and actual free Arc Input, Textarea, Button, ActionButton, PasswordField, CopyButton and FileDropzone. All selection is local. Motion only belongs to the supplied controls. No custom animation, scores, uploads, fake progress or success.

State belongs in a production controller used by both React and Node tests. Drafts survive route changes; passphrases live only in mounted form state, clear after action and never enter the controller. Errors survive navigation as visible global feedback. The core, vault and draft contracts are retained. Reporting adds a manual location filter; file tools add a separate local Content Credentials inspection action.
