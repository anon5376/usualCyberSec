# usualCyberSec design

The user requested a much simpler site, like a straightforward student-built web project. The current design uses a white page, Arial/system text, ordinary blue links and buttons, simple rectangular borders, and a centered single-column workspace. It replaces the earlier charcoal/copper dashboard.

The page is at most 880px wide, with one set of outer gutters. Main navigation and task links wrap on small screens. Forms use normal HTML controls, explicit labels, visible keyboard focus and readable error messages. Long incident text wraps. Cases, reporting, guides and the vault use the same simple styling.

The small [u] text mark remains. Custom fonts, terminal decoration, rounded dashboard panels and the secondary ASCII explanation panel are removed from the visible design. No external font, framework or service is loaded. Runtime behavior and privacy boundaries remain unchanged.
