# usualCyberSec interface

Mode: operate. A calm incident-response desk: warm paper, near-black ink, restrained ochre actions and olive completion states. Dense evidence uses monospace only for hashes, timestamps, and hostnames. Serif titles give the product a human, editorial voice; controls use system sans. No external fonts or image calls.

The workspace has persistent navigation, a visible session-storage state, an obvious new-incident action, and route-specific task panels. Overview explains a three-step process; tools always put inputs before uncertainty and next actions. Real empty states, no invented incident statistics or activity. Mobile navigation becomes an accessible horizontal strip. All user inputs remain on device.

The initial direction is the response field manual (working assumption, not a recorded user preference). Other considered structures: help desk, evidence ledger, account rescue map, verification workbench, public service form, newsroom source desk. No generated decorative imagery is needed for the task.
